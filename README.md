## Local Setup & Testing

This project leverages a **Bring Your Own Key (BYOK)** architecture for maximum portability. No hardcoded credentials are included. You can securely provide your Gemini API key through the "Settings" modal in the UI.

To verify the system's reliability, run the test suite:
```bash
npm test
```
The suite includes **139 passing unit tests** validating the adaptive engine and integrations, achieving **96.5% code coverage**.
